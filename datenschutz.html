Hinweise zu dieser Designvorschau und zur Kontaktaufnahme.

Diese Designvorschau

Die Vorschau wird über GitHub Pages bereitgestellt. Beim Aufruf verarbeitet GitHub technische Verbindungsdaten; dazu kann auch Ihre IP-Adresse gehören. Informationen dazu finden Sie in der Datenschutzerklärung von GitHub.

Keine Analyse- oder Werbefunktionen

Diese Vorschau bindet keine Analyse- oder Werbedienste ein. Die Website setzt selbst keine Cookies und speichert keine Formularangaben im Browser-Speicher. Schriftdateien, Bilder und technische PDF-Dokumente werden zusammen mit der Website ausgeliefert.

Projektanfrage per E-Mail

Die Felder auf der Kontaktseite dienen zur Vorbereitung einer E-Mail. Beim Ausfüllen werden keine Formulardaten an einen Server übermittelt. Beim Öffnen des E-Mail-Programms wird der vorbereitete Text an Ihr E-Mail-Programm übergeben. Erst wenn Sie dort versenden, wird die Nachricht an office@policell.at verschickt. Für die E-Mail-Verarbeitung gelten ergänzend die Bedingungen Ihres E-Mail-Anbieters.

Externe Links

Links zu Routenplanung, Videos und dem bisherigen Unternehmensauftritt laden externe Seiten erst, wenn Sie diese öffnen. Für diese Seiten gelten die jeweiligen Datenschutzhinweise.

Datenschutz bei Policell

Die bestehenden Informationen zur Datenverarbeitung durch Policell, zu Ansprechpartnern und zu Betroffenenrechten finden Sie in der Datenschutzerklärung auf policell.at.

Diese Hinweise beschreiben die Funktionen der Designvorschau. Für einen späteren Unternehmensbetrieb müssen Betreiberangaben und Datenschutzerklärung auf das tatsächliche Hosting und die eingesetzten Dienste abgestimmt werden.
